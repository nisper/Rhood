## Использованные Figma-сущности

- Library: `Parser – Components`.
- Component set: `table-cell`, импортированный по ключу `a3d030d4466526230fffa01dd8659a6b1c831ecb`.
- Instances: 20 instances `table-cell` — четыре строки по пять ячеек.
- Variants для заголовков: `role=head`, `type=text`, `sizeSmall=false`, `paddingX=true`.
- Variants для данных: `role=body`, `type=text`, `sizeSmall=false`, `paddingX=true`.
- Component property: `slot#11024:0`; текст добавлен в slots instances.
- Figma variable: `text/neutral/primary` из `Parser – Components`, привязана к fills созданных текстовых слоёв.

## Собранные вручную элементы

Вручную собраны следующие элементы:

- Frame `Таблица задач` с вертикальным auto layout.
- Четыре row frames с горизонтальным auto layout: `Заголовки`, `Строка 1`, `Строка 2`, `Строка 3`.
- Нижний stroke у каждой строки.
- 20 текстовых слоёв внутри slots ячеек.

Контейнер и строки собраны вручную, потому что в [[docs/patterns/table.md|паттерне таблицы]] указан способ их сборки через auto layout, но не указан готовый компонент контейнера или строки. Ячейки собраны только из instances `table-cell`.

## Расхождения с инструкциями проекта

- Нижние borders строк не привязаны к Figma variable `theme / border/light`. [[docs/patterns/table.md|Паттерн таблицы]] требует эту привязку. Расхождение допущено при создании каркаса: запрос variable по ID не вернул variable, поэтому для strokes назначен прямой цвет `#E8E8E8`. Позднее эта привязка не исправлялась.
- В двух ячейках комментариев исходные прочерки заменены на «Без комментария». Это сделано на финальном этапе, чтобы не использовать прочерк для пустого значения, как требует [[docs/patterns/table.md|паттерн таблицы]].
- Стандартные текст и `help icon` в slots заголовочных instances не удалены, а скрыты через instance overrides. Новые заголовки добавлены отдельными текстовыми слоями в те же slots.
