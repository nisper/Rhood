| Колонка     | Подходящий input                           | Почему                                                                                                                        |
| ----------- | ------------------------------------------ | ----------------------------------------------------------------------------------------------------------------------------- |
| Задача      | `search-input`                             | Поиск по названию задачи; лучше объединить с поиском по комментарию.                                                          |
| Статус      | `toggle-chip`, multi select                | Значений всего три: «Не начато», «В работе», «Запланировано» — чипы быстрее обычного select.                                  |
| Исполнитель | `autocomplete`, multi select               | Исполнителей со временем станет больше десяти; поиск по имени здесь полезен.                                                  |
| Срок        | Два `date-input`: «С» и «По»               | Нужен диапазон дат. Рядом можно добавить быстрые значения: «Сегодня», «Эта неделя», «Просрочено», «Без срока».                |
| Комментарий | Не отдельный текстовый фильтр по умолчанию | Его текст стоит включить в общий `search-input`. Если нужно, добавим только criterion «Есть комментарий» / «Нет комментария». |
 
🔲 Ширина контейнера с фильтром  
 Ширина 1373 px. У меня есть правило: Все мои контейнеры имеют ширину fill, то есть 100% доступного им пространства. Формально, твоя ширина правильная и совпадает с родителем, но это пока я ширину родителя менять не начал.
  
🔲 Фиксированная высота вложенных строк  
  
Она фиксированная и это создает две проблемы:  
  

1. Тебе надо принимать решение, какой она должна быть, а это время, токены, мои нервы;
2. Это не гибко в работе, если вложенные объекты будут менять высоту;
3. Кнопка в первой строке обрезалась.
