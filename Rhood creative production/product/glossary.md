# Продуктовый глоссарий

Используй этот файл, чтобы продуктовый язык оставался единым в документации, интерфейсе, дизайне и коде.

| Термин              | Значение                                                                                                                                                                                                                      | Заметки                                                                                     |
| ------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------- |
| RHOOD               | Внутренний продукт "Этажей" для набора базы объектов недвижимости.                                                                                                                                                            | Можно использовать как название системы в документации и рабочих обсуждениях.               |
| СПН                 | Специалист по недвижимости.                                                                                                                                                                                                   | Синонимы: риэлтор, специалист, пользователь продукта.                                       |
| Объект недвижимости | Реальный объект недвижимости, который может быть опубликован на одной или нескольких площадках.                                                                                                                               | Базовая сущность предметной области.                                                        |
| Объявление          | Публикация объекта недвижимости на конкретной площадке или сайте-источнике.                                                                                                                                                   | Один объект может иметь несколько объявлений в разных источниках.                           |
| Группа объявлений   | Набор объявлений из разных источников, которые относятся к одному и тому же объекту недвижимости.                                                                                                                             | Можно использовать в выдаче, когда система группирует несколько объявлений одного объекта.  |
| Уникальный объект   | Объект недвижимости, с которым "Этажи" еще не работают и которого нет в текущей базе как известного объекта. Для участков этот признак автоматически не проверяется.                                                          | Основной результат работы парсера.                                                          |
| Дубль               | Объект, который уже присутствует в базе "Этажей" или совпадает с уже найденным объектом.                                                                                                                                      | Такие объекты не должны попадать в основной список для обработки.                           |
| Мэтчинг покупателей | Автоматическая или ручная проверка объекта из парсера на наличие подходящих покупателей в базе "Этажей". Подходящим покупателем считается заявка на покупку с заполненной потребностью клиента, которой соответствует объект. | В интерфейсе обычно выражается бинарным признаком наличия совпадения.                       |
| Набор базы          | Продуктовый процесс поиска и отбора новых объектов для работы.                                                                                                                                                                | Может использоваться как название раздела интерфейса.                                       |
| Подменный номер     | Временный номер телефона, который передает агрегатор объявления для связи с собственником.                                                                                                                                     | Используется действием `Позвонить`; прямой номер собственника может быть недоступен.        |
| Космос              | CRM "Этажей", в которой хранятся объекты недвижимости, ведутся сделки. Сюда сохраняются объекты из парсера, если собственник готов работать с Этажами.                                                                        | Отдельный сервис по отношению к RHOOD.                                                      |
| Echat               | Корпоративный мессенджер "Этажей".                                                                                                                                                                                            | Один из каналов уведомлений о новых объектах по подписке.                                   |
| RHOOD Plus          | Подписка в RHOOD.                                                                                                                                                                                                             | Связана с подпиской на поиск.                                                               |
| Подключенный город  | Город, для которого RHOOD запущен, просматривает источники и показывает выдачу сотрудникам этого города.                                                                                                                      | Подключение платное, оплачивает город.                                                      |
| Город-спутник       | Близко расположенный город, который подключается вместе с основным городом.                                                                                                                                                   | Пользователи такого контура видят основной город и все города-спутники в выдаче и фильтрах. |

## Заметки о названиях

- По возможности используй один и тот же термин в продуктовых документах, UI-текстах и коде.
- Добавляй альтернативные или отклоненные названия, если термин обсуждался.
