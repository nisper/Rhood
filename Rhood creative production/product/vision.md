# Видение продукта

## Краткое описание

Парсер RHOOD — внутренний продукт риэлторской компании "Этажи" для набора базы объектов недвижимости. Система собирает объекты из агрегаторов и сайтов агентств недвижимости по городу, сравнивает их с базой "Этажей" и исключает уже известные объекты. В результате специалист по недвижимости получает список уникальных объектов, с которыми компания еще не работает.

## Аудитория

- Основные пользователи: специалисты по недвижимости, риэлторы, СПН.

## Проблема

Риэлторам сложно вручную просматривать все городские источники недвижимости и понимать, какие объекты уже есть в базе "Этажей", а какие еще не охвачены. Без автоматического сравнения специалисты тратят время на дубли, пропускают новые возможности и медленнее пополняют базу актуальными объектами.

## Ценность

Продукт должен ускорить набор базы, сократить ручную проверку дублей и сделать поиск новых объектов более надежным. Риэлтору должно быть проще сосредоточиться на действительно новых предложениях вместо повторной обработки уже известных объектов.

## Продуктовые принципы

- Показывать риэлтору только те объекты, которые требуют действия.
- Минимизировать шум от дублей.
- Делать происхождение и статус объекта понятными для быстрой оценки и взятия в работу.
- Показывать пользователю только те города, которые доступны ему в рамках его городского контура.

## Не-цели

- Не-цель 1: не заменять CRM, в нем нельзя провести сделку.
- Не-цель 2: не давать обычным пользователям просматривать все подключенные города вне их городского контура.
