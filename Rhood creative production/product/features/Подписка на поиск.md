# Подписка на поиск

## Краткое описание

Подписка на поиск позволяет пользователю получать новые объекты, которые соответствуют сохранённым параметрам поиска.

## Потребность пользователя

СПН нужно узнавать о подходящих объектах без постоянной ручной проверки выдачи.

## Основной сценарий

1. Меняет параметры фильтра;
2. Сохраняет поиск;
3. Подписывается на поиск.

## Ограничения

- Без подписки [[Подписка RHOOD Plus|RHOOD Plus]] пользователь может подписаться на 1 поиск;
- С подпиской [[Подписка RHOOD Plus|RHOOD Plus]] — на 5 поисков.

## Способы привлечения к подписке

### Баннер над выдачей объектов

Когда пользователь меняет параметры фильтра в выдаче объектов, система показывает над выдачей баннер «Не упустите новые объекты». Баннер предлагает подписаться на поиск с текущими параметрами фильтра.

Баннер — один из способов привлечения к подписке на поиск. Он не определяет основной сценарий подписки и не является единственным способом подписаться на поиск.

\*\*Текст на баннере

|     | Заголовок                 | Подпись                                                                                         | Кнопка               |
| --- | ------------------------- | ----------------------------------------------------------------------------------------------- | -------------------- |
| А   | Не упустите новые объекты | Подпишитесь на поиск — получайте новые объекты сразу после публикации                           | Подписаться на поиск |
| Б   | Не упустите новые объекты | Подпишитесь на поиск — новые объекты будем отправлять в Telegram и Echat сразу после публикации | Подписаться на поиск |

## Связанный интерфейс

- Экран: Набор базы, список объектов.
- Компоненты: фильтры, выдача объектов, баннер «Не упустите новые объекты».
- Расположение баннера: над выдачей объектов.

## Связанные данные

- Сущности: поиск, параметры фильтра, сохранённый поиск, подписка на поиск.
- Входные данные: параметры фильтра пользователя.
- Выходные данные: сохранённый поиск и подписка на поиск.
