# Phone

Поле для ввода номера телефона.

## Маска

Для ввода используется маска для российского номера: `+7 922 123 45 67`.

## Основное правило

- Для ввода номера телефона используй component set `input phone` по `source.figma_url` из JSON-блока в [[docs/components/input-phone.md|документации input phone]].
