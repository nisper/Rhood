# Форма

Форма — объединённый набор input’ов, через который пользователь задаёт или меняет данные для одной задачи. Форма может использоваться в авторизации, профиле, настройках и фильтрах.

## Маршрутизация

Если задача затрагивает отдельные поля формы — их конструкцию, [[docs/components/control-label.md|control-label]], обязательность или валидацию, сначала читай [[docs/patterns/input.md|input]].

## Когда использовать

- Пользователю нужно заполнить несколько связанных значений;
- Значения образуют одну задачу: авторизацию, редактирование профиля, настройку или фильтрацию выдачи.

## Состав

| Часть           | Роль                                                                     |
| --------------- | ------------------------------------------------------------------------ |
| Контейнер формы | Объединённый набор [[docs/patterns/input.md]]’ов одной задачи.          |
| Input           | Поле или [[docs/patterns/input-component.md]], через который пользователь задаёт или меняет значение. |

## Actions

Actions могут применяться к значениям формы, но не обязаны входить в её контейнер. Их наличие и расположение определяет конкретная фича.

## Структура

```text
Контейнер формы
├── Input
├── Input
└── Input
```

- Конструкцию каждого input определяет [[docs/patterns/input.md|паттерн input]].

## Layout и responsive-поведение

- Расположение [[input]]’ов внутри формы на desktop, tablet и mobile определяет конкретная фича;
- Форма не задаёт внешние отступы: их определяет родительский layout.

## Формы фильтров

Форма фильтров задаёт criteria, которые меняют выдачу. Например: район, цена и комнатность. Для такого сценария применяются общие правила формы, а состав criteria и способ применения значений определяет конкретная фича.
