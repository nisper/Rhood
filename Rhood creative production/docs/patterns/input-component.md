# Компонент ввода

Компонент ввода — компонент, через который пользователь задаёт или меняет значение.

| Компонент                                   | Назначение                                                                                                                                                                                                                                                                                                                          |
| ------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| [[docs/components/add-any-file.md]]         | Добавить один или несколько файлов через выбор или перетаскивание.                                                                                                                                                                                                                                                                  |
| [[docs/components/add-photos.md]]           | Добавить фотографии. Компонент также показывает состояние загрузки.                                                                                                                                                                                                                                                                 |
| [[docs/components/autocomplete.md]]         | Выбрать одно или несколько значений. Стоит использовать, если в списке больше 10 вариантов. Может работать как single select и multi select.<br><br>Главное отличие — можно искать по списку вариантов.                                                                                                                             |
| [[docs/components/checkbox.md]]             | Выбрать одно или несколько значений в группе.                                                                                                                                                                                                                                                                                       |
| [[docs/components/input-confirm-code.md]]   | Ввести код подтверждения.                                                                                                                                                                                                                                                                                                           |
| [[docs/components/input-date.md]]           | Ввести дату.                                                                                                                                                                                                                                                                                                                        |
| [[docs/components/input-password.md]]       | Ввести пароль с возможностью показать значение.                                                                                                                                                                                                                                                                                     |
| [[docs/components/input-phone.md]]          | Ввести российский номер телефона по маске `+7 922 123 45 67`.                                                                                                                                                                                                                                                                       |
| [[docs/components/input-number.md]]         | Ввести числовое значение.                                                                                                                                                                                                                                                                                                           |
| [[docs/components/input-date-range.md]]     | Ввести диапазон дат.                                                                                                                                                                                                                                                                                                                |
| [[docs/components/input-number-range.md]]   | Ввести числовой диапазон.                                                                                                                                                                                                                                                                                                           |
| [[docs/components/input-search.md]]         | Ввести поисковый запрос.                                                                                                                                                                                                                                                                                                            |
| [[docs/components/select.md]]               | Выбрать одно или несколько значений из списка, когда поиск не нужен. Может работать как single select и multi select.                                                                                                                                                                                                               |
| [[docs/components/switch.md]]               | Включить или выключить настройку.                                                                                                                                                                                                                                                                                                   |
| [[docs/components/input-text.md]]           | Ввести текст в одну строку.                                                                                                                                                                                                                                                                                                         |
| [[docs/components/input-text-multiline.md]] | Ввести текст в несколько строк.                                                                                                                                                                                                                                                                                                     |
| [[docs/components/toggle-button.md]]        | Выбрать или отменить выбор одного варианта.                                                                                                                                                                                                                                                                                         |
| [[docs/components/toggle-button-group.md]]  | Выбрать один вариант из связанных toggle button.                                                                                                                                                                                                                                                                                    |
| [[docs/components/toggle-chip.md]]          | Выбрать один или несколько вариантов из набора.<br><br>Интерактивный input-component: в отличие от [[docs/components/chip.md]], меняет выбранное значение по нажатию.<br><br>Альтернатива [[docs/components/select.md]].<br><br>Стоит использовать, если в выборе до 10 вариантов. Может работать как single select и multi select. |
