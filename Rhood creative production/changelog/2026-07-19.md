## Favorite buttons

- [favorite button](https://www.figma.com/design/MbjYVdGZqH95blipWMHXtp/Parser-%E2%80%93%C2%A0Components?node-id=10225-1705&t=lsaJSY40YKYQ6cdt-11)
- [favorite icon button](https://www.figma.com/design/MbjYVdGZqH95blipWMHXtp/Parser-%E2%80%93%C2%A0Components?node-id=968-779&t=lsaJSY40YKYQ6cdt-11)

### Что изменилось

- `favorite button` оформлен как отдельный component set для текстового действия избранного.
- У `favorite button` есть variants `style`, `checked`, `size`, `state`.
- `checked=false` использует текст `В избранное` и иконку `favorite_outline`.
- `checked=true` использует текст `В избранном` и иконку `favorite_filled`.
- `favorite icon button` оформлен как отдельный component set для компактного действия избранного без label.
- У `favorite icon button` есть variants `checked`, `state`, `size`.

### Почему

- Развели текстовую кнопку избранного и компактную icon-only кнопку избранного как две специализированные сущности.
- Это снимает путаницу с icon-only версией внутри обычного `button`: теперь это не базовый вариант кнопки, а отдельный сценарный компонент.
