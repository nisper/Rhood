# Инструкции для агента

## Стиль общения

- Обращайся к пользователю на ты;
- По умолчанию отвечай кратко;
- Не перегружай ответ деталями, если без них можно передать суть;
- Если пользователю чего-то не хватит, он уточнит отдельным вопросом.

## Тематические инструкции

Перед задачей проверь, есть ли для неё подходящая инструкция в папке [[_instructions|_instructions]], и следуй ей;

- Для UI-задач и правок макетов в Figma сначала читай [[_instructions/figma.md|figma]];
- Для задач по текстам и оформлению документов сначала читай [[_instructions/copy-guidelines.md|copy-guidelines]];
- Для создания или обновления документации фич сначала читай [[_instructions/feature-documentation.md|feature-documentation]];
- Для создания или обновления документации компонента сначала читай [[_instructions/component-documentation.md|component-documentation]].
### Порядок для документов

- При создании или правке любого текстового документа, включая файлы в `_instructions`, сначала читай [[_instructions/copy-guidelines.md|copy-guidelines]], затем тематическую инструкцию;
- Перед завершением правки документа проверяй оформление списков по `copy-guidelines.md`: самостоятельные пункты начинаются с прописной буквы и заканчиваются точкой; пункты, продолжающие вводную фразу, начинаются со строчной буквы, разделяются точкой с запятой, а последний заканчивается точкой;
- В Markdown-документах используй Obsidian-ссылки в формате `[[путь/к/файлу.md|короткое имя]]`;
- Если ссылка внутри таблицы делай ее в виде `[[путь/к/файлу.md]]` без алиаса.

## Обсуждение Figma

В задачах по Figma говори в первую очередь категориями Figma: `component properties`, `variants`, `component sets`, `instances`, `variables`, `styles`, `modes`, `overrides`.

Не вводи кодовые абстракции: `props`, `CSS variables`, `runtime inheritance`, `implementation APIs`, пока обсуждение явно не перешло к коду.

Если идея пришла из реализации, но влияет на Figma, сначала переведи её в ближайшую Figma-категорию.

| Вместо          | Говорить                                 |
| --------------- | ---------------------------------------- |
| Добавить режим  | Добавить значение `component property`   |
| CSS variable    | Figma variable или variable alias        |
| Prop            | `Component property`                     |
| Runtime inherit | Явная настройка variant/property в Figma |
