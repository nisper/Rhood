# Rhood

Прототип интерфейса для внутреннего продукта RHOOD компании "Этажи".

Описание продукта, продуктовая логика и основные документы находятся в [docs/product](./docs/product/README.md).

## Продуктовая документация

- [Продуктовая документация](./docs/product/README.md)

## Технологический стек

Прототип приложения на React и TypeScript, собранный на Vite с Tailwind CSS, shadcn/ui и lucide-react.

## Скрипты

- `npm run dev` запускает локальный сервер Vite.
- `npm run build` проверяет типы и собирает приложение.
- `npm run preview` запускает локальный предпросмотр собранного приложения.
- `npm run lint` запускает ESLint.

## Структура

- `src/components/ui` компоненты shadcn/ui.
- `src/components/prototype` оболочки компонентов, используемые только в прототипе.
- `src/screens` будущие экраны продукта.
- `src/data` тестовые данные для прототипа.
- `docs` заметки и документация проекта.
