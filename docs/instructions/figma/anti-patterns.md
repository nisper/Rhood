# Anti-Patterns

Этот файл будет фиксировать решения, которых нужно избегать при сборке макетов.

Добавляй сюда только повторяющиеся ошибки и правила, которые важно быстро проверять перед завершением работы.

## Общие Антипаттерны

- Декоративные изменения без продуктового смысла.
- Усложнение интерфейса ради впечатления.
- Смешивание нескольких гипотез в одном варианте без необходимости.
- Случайные названия и термины, не совпадающие с документацией.
- Макеты, которые красиво выглядят, но не помогают принять решение.
- Новый компонент или новый паттерн, замаскированный под небольшую правку.
- Ручные цвета, размеры текста и отступы там, где есть системные стили, tokens или правила.
- Перекрытие существующих экранов, компонентов, заметок или рабочих областей новым вариантом.
