# Figma Instructions

Используй этот раздел как карту правил для сборки макетов в Figma.

Главный входной документ: `../working-in-figma.md`. Он задает общий протокол работы с Figma-задачами. Этот раздел описывает конкретные правила сборки интерфейсов.

## Как пользоваться

1. Определи, какую сущность нужно собрать или изменить.
2. Открой соответствующий файл в `entities/`.
3. Если нужно выбрать компонент, смотри `component-groups.md`.
4. Если нужно принять layout-решение, смотри `layout-rules.md`.
5. Если решение похоже на новый паттерн или новый компонент, сначала зафиксируй вопрос пользователю.

## Граница Ответственности

- `../working-in-figma.md` отвечает на вопрос: как вести себя в Figma-задаче.
- `layout-rules.md` отвечает на вопрос: как располагать блоки и выбирать sizing.
- `component-groups.md` отвечает на вопрос: какие группы компонентов использовать и как не создавать новое без необходимости.
- `entities/` отвечает на вопрос: как устроена конкретная интерфейсная сущность.
- `anti-patterns.md` отвечает на вопрос: чего избегать перед завершением работы.

## Структура

- `layout-rules.md` — базовый layout, модуль, отступы, правило внутреннего и внешнего.
- `component-groups.md` — группы компонентов и правила выбора между ними.
- `anti-patterns.md` — запрещенные и нежелательные решения.
- `entities/` — правила сборки интерфейсных сущностей.

## Сущности

- `entities/page.md` — страница личного кабинета.
- `entities/drawer.md` — drawer.
- `entities/modal.md` — modal.
- `entities/table.md` — таблица или список.
- `entities/form.md` — форма.
- `entities/filters.md` — фильтры и управление представлением.
- `entities/empty-state.md` — пустые состояния.
