# Оформление code snippets

## Назначение

Используй эти правила для примеров кода в Витрине компонентов. Snippet объясняет, какой prop или состав компонентов создаёт показанный выше результат.

## Содержание

- Показывай только короткий JSX-фрагмент компонента с prop или slot, который влияет на демонстрируемый вариант.
- Не добавляй imports, объявление компонента-примера, `return` и `export`.
- Snippet должен соответствовать демонстрации рядом. Если вариант меняет prop, покажи этот prop непосредственно на компоненте, например `appearance="primary"`.
- Сохраняй только ту часть структуры JSX, которая объясняет положение изменяемого prop или slot.
- Не включай служебные детали Витрины, не нужные пользователю компонента: внутренние классы, тестовые обработчики и обвязку страницы.

## Минимальная подсветка

Основа текста — `--rh-theme-text-neutral-primary`. Не окрашивай весь код одним цветом: выделяй только роли, которые помогают прочитать пример.

| Роль | Примеры | Цвет |
| --- | --- | --- |
| Имена React-компонентов | `Button`, `ShowcaseSection` | `--rh-palette-purple-700` |
| JSX props | `appearance`, `showcase`, `title` | `--rh-theme-text-info` |
| Строки, числа и boolean-значения | `"primary"`, `480`, `true` | `--rh-theme-text-success` |
| Пунктуация и синтаксические скобки | `{}`, `()`, `=`, JSX-теги | `--rh-theme-text-neutral-secondary` |

Не используй `--rh-theme-text-error` и `--rh-theme-text-warning` для обычного синтаксиса: они сохраняют смысл ошибки и предупреждения в интерфейсе.

## Контейнер и типографика

- Используй семантику `<pre><code>…</code></pre>`.
- Шрифт — моноширинный, размер `14px`, line-height `20px`.
- Фон — `--rh-theme-fill-neutral`, радиус — `--rh-sizing-border-radius-md`, padding — `16px`.
- Не переноси строки автоматически: при недостатке места показывай горизонтальную прокрутку.
- Не добавляй номера строк, копирование и язык-переключатель, пока для них нет отдельной задачи.

## Связь с ShowcaseSection

Передавай snippet в опциональный prop `ShowcaseSection.codeSnippet`. Он выводится после Showcase и остаётся частью одной демонстрационной секции.

## Проверка

- Визуальный пример и snippet показывают один и тот же вариант.
- Из snippet можно быстро понять, какой prop отвечает за изменение.
- Все роли подсветки различимы на нейтральном фоне и используют существующие токены RHOOD.
