# Сборка сцены

## Таблицы

Когда я прошу тебя собрать, что-то на компоненте `Table`.

- Используй компонент:
	- `src/components/ui/table.tsx`
	- `src/components/ui/table-row.tsx`
	- `src/components/ui/table-cell.tsx`;
- Всегда используй компонент «как есть»:
	- Не перекрашивай элементы компонента;
	- Не меняй стили компонента и вложенных элементов;
	- Не меняй никакие размеры.
- Если в колонке есть единицы измерения (₽, м², %, и так далее), указывай их через запятую в лейбле шапки, например: «Площадь, м²». В ячейках значения указывай без единиц измерения, чтобы не дублировать их.
- Если заменяемая структура «напрашивается» кастомными стилями к компоненту, на который заменяем, сначала спроси меня, стоит ли перенести эти стили на новую версию.

## Даты

- Если выводишь даты, добавляй CSS-свойство `font-variant-numeric: tabular-nums`.
