# Table

## Выбор строк

- Чекбокс в шапке работает только со строками текущей страницы пагинации.
- Если выбрана часть строк текущей страницы, чекбокс в шапке имеет состояние `indeterminate`. Нажатие выбирает все строки этой страницы.
- Если выбраны все строки текущей страницы, чекбокс в шапке `checked`. Нажатие снимает выбор со всех строк этой страницы.
- `Table` получает настройку `selection`: `rowIds` текущей страницы, `selectedIds` всех страниц и `onSelectedIdsChange` для управляемого состояния.
- Для строк с checkbox передайте `rowId`; `TableCell` сам отображает выбранность строки, состояние шапки и обрабатывает выбор текущей страницы.

## Размер колонок

По умолчанию колонка имеет ширину самого широкого содержимого. Для каждой колонки используется один режим ширины во всех её ячейках:

- `content` — по содержимому; это значение по умолчанию.
- `fill` — колонки с этим значением делят доступную ширину таблицы поровну.
- Число — фиксированная ширина в пикселях, например `width={160}`.

В режимах `fill` и фиксированной ширины текст переносится. Сокращение текста через «…» добавляется только в отдельных сценариях, когда это явно описано.

## Горизонтальные отступы

`paddingX` включён по умолчанию и добавляет внутренние горизонтальные отступы ячейки. `paddingX={false}` используют только когда эти отступы уже задаёт родитель.

## Сортировка

- Сортируемый заголовок получает `sort` и обработчик нажатия.
- Пока сортировка не выбрана, стрелки нет. Первое нажатие задаёт `sortDirection="asc"` и показывает стрелку вниз.
- Повторное нажатие на тот же заголовок меняет направление на `desc` и показывает стрелку вверх.
- Стрелка есть только у колонки, по которой таблица сейчас отсортирована.

## Содержание колонок

Единицы измерения и валюта, одинаковые для всей колонки, указываются в шапке: например, «Стоимость, ₽» или «Площадь, м²». В ячейках остаются сами значения.

## Help icon

Help icon находится сразу после текста заголовка и не прижимается к правому краю ячейки.

## Обводка

У Table всегда есть скругление `rounded-lg`. Обводку добавляют только при необходимости: `1px solid border-light`. Если обводка не нужна, свойство `border` не задают.
