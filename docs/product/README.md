# Продуктовая документация

RHOOD — внутренний продукт компании "Этажи" для набора базы объектов недвижимости. Система собирает объявления из внешних источников, сравнивает их с базой "Этажей", исключает уже известные объекты и показывает СПН только уникальные объекты, с которыми компания еще не работает.

Авторизоваться в RHOOD может любой сотрудник компании "Этажи", но выдача показывается только для подключенных городов. Пользователь работает в рамках своего городского контура: видит объекты только по доступным ему городам. Если вместе с основным городом подключены города-спутники, они также доступны в выдаче и фильтрах.

Эта папка хранит знания о продукте: что это за продукт, для кого он создается, какие проблемы решает и как должны работать отдельные части функционала.

## Типы продуктовых документов

- [Карта функционала](./feature-map.md) описывает, что есть в продукте: области, фичи, их назначение, ссылки на подробные описания и статус.
- [Карта пользовательских сценариев](./scenario-map.md) описывает, как пользователи работают с продуктом: ключевые пути, роли, цели, ссылки на сценарии и статус.

## Предлагаемый процесс

1. Опиши направление продукта в [видении](./vision.md).
2. Добавь основные продуктовые области в [карту функционала](./feature-map.md).
3. Создай отдельный файл в [фичах](./features/) для каждой значимой возможности продукта.
4. Добавь основные пути пользователя в [карту сценариев](./scenario-map.md).
5. Создай отдельный файл в [сценариях](./scenarios/) для каждого значимого пользовательского пути.
6. Добавляй термины в [глоссарий](./glossary.md), когда названия начинают иметь значение.
