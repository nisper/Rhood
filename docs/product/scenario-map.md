# Карта пользовательских сценариев

Этот документ хранит основные пользовательские сценарии RHOOD и ссылки на подробные описания путей пользователя.

## Сценарии

| Сценарий            | Пользователь | Описание                                                                                         | Документы               | Статус   |
| ------------------- | ------------ | ------------------------------------------------------------------------------------------------ | ----------------------- | -------- |
| Набор базы объектов | СПН          | СПН открывает свежую выдачу, прозванивает новые объекты и сохраняет согласившиеся объекты в CRM. | [[Набор базы объектов]] | Черновик |

## Статусы

- `Идея` - сценарий стоит зафиксировать, но он еще не разобран.
- `Черновик` - сценарий описывается или проверяется.
- `Готово к дизайну` - сценарий достаточно понятен для проектирования интерфейса.
- `Готово к работе` - сценарий достаточно понятен для реализации.
- `В работе` - сценарий активно проектируется или разрабатывается.
- `Запущено` - сценарий доступен пользователям.
- `На паузе` - сценарий осознанно отложен.

## Заметки

- Сценарии описывают путь пользователя, а не устройство фичи или техническую реализацию.
- Один сценарий может затрагивать несколько фич.
- Лучше ссылаться на отдельные файлы сценариев, чем добавлять сюда длинные описания шагов.
