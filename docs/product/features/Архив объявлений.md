# Архив объявлений

## Потребность пользователя

СПН нужно просматривать снятые с публикации объявления и анализировать предложение на рынке за прошедший период.

## Основной сценарий

1. Открывает раздел «Архив»;
2. Настраивает фильтры по объектам;
3. Сравнивает объявления и параметры предложения за выбранный период;
4. При необходимости открывает подробности объявления.

## Правила доступа

- Архив доступен пользователям с подпиской [[Подписка Rhood Plus|RHOOD Plus]].
- Пользователю без подписки показывается посадочная страница с предложением оформить RHood Plus.
- Посадочная страница сообщает, что в архиве собраны объявления за последние 6 месяцев.
- Все пользователи видят один и тот же состав архива; пользовательские фильтры могут сузить отображаемую выдачу.

## Состав выдачи

- Только снятые с публикации объявления всех типов объектов, с которыми работает Rhood, опубликованные за последние 6 месяцев.
- Для каждого объявления хранится только последнее известное состояние; история изменений цены и другие версии объявления не сохраняются.
- Общие колонки для всех типов: расположение, цена, источник, автор, дата публикации и дата последнего изменения информации об объекте на площадке. Последняя показывается в колонке «Снят», хотя фактическая дата снятия объявления неизвестна.
- Остальные колонки зависят от типа недвижимости:
  - **Квартира:** комнатность, площадь, этаж, цена за м².
  - **Дом:** «Площадь, м²», «Площадь, сот», цена за м².
  - **Участок:** «Площадь, сот», цена за сотку.
- Колонки, относящиеся к другим типам объектов, не показываются.

## Действия с объявлением

- Пользователь может просмотреть информацию об объекте, включая 3 фотографии.

## Связь с актуальной выдачей

Объявления, которые продолжают публиковаться, доступны в обычной выдаче «Набор базы».

## Связанный интерфейс

- Экраны: «Архив», «Архив — нет подписки».
- Компоненты: фильтры, таблица архивной выдачи, превью архивной таблицы, посадочная страница RHood Plus.
- Интерфейс прототипа: [список объявлений](../../../src/screens/apartment-listings-screen.tsx), маршруты — [prototype-router.tsx](../../../src/components/prototype/prototype-router.tsx).

## Связанные данные

- Сущности: объявление, параметры объекта, источник, автор, дата публикации, период архива, подписка RHood Plus.
- Входные данные: объявления из внешних источников и параметры фильтров пользователя.
- Выходные данные: отфильтрованный список архивных объявлений.
