# Сохраненные фильтры

## Краткое описание

Пользователь может сохранить набор параметров фильтра, если хотя бы один параметр отличается от значения по умолчанию. Сохраненный набор можно быстро выбрать повторно, чтобы не задавать параметры заново.

## Потребность пользователя

- Быстро применять часто используемые наборы параметров и не вводить их повторно.
- [[Подписка на поиск|Подписаться на сохраненный поиск]].

## Правила

- Сохранять можно фильтр с параметрами, отличными от значений по умолчанию.
- Пользователь может сохранить до 10 фильтров.
- Лимит одинаковый для пользователей с RHOOD Plus и без подписки.

## Связь с подпиской на поиск

[[Подписка на поиск]] — отдельная фича. Сохраненный фильтр помогает повторно применить параметры, а подписка на поиск позволяет получать новые объекты, соответствующие параметрам поиска. Само сохранение фильтра не оформляет подписку.

Пользователь может применить сохраненный фильтр и затем подписаться на поиск с этими параметрами. Лимиты сохраненных фильтров и подписок независимы: для фильтров действует лимит 10, для подписок — лимиты, описанные в [[Подписка на поиск]].
