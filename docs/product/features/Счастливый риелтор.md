# «Счастливый риэлтор» — индикатор привлекательности объекта

Индикатор помогает риэлтору быстро заметить квартиру, у которой есть преимущество перед похожими предложениями и повод заняться ею сейчас.

## Как рассчитывается индикатор

Бейдж появляется у **активного объявления о продаже квартиры целиком от собственника**, когда подтверждён **хотя бы один признак из каждой группы**.

| Группа                     | Признак                      | Когда засчитывается                                                                                 |
| -------------------------- | ---------------------------- | --------------------------------------------------------------------------------------------------- |
| Привлекательность квартиры | Цена ниже похожих объявлений | Основная оценка готова и актуальна, данных для сравнения достаточно, цена ниже похожих предложений. |
| Привлекательность квартиры | Высокая ликвидность          | RELIC завершил расчёт и подтвердил высокую ликвидность.                                             |
| Повод действовать сейчас   | Новое объявление             | С момента обнаружения объявления в RHood прошло меньше 12 часов.                                    |
| Повод действовать сейчас   | Есть подходящие покупатели   | Последняя завершённая проверка выявила хотя бы одну доступную подходящую заявку.                    |

Например, **высокая ликвидность + подходящие покупатели** дают бейдж, даже если оценка цены ещё готовится. **Цена ниже похожих объявлений + высокая ликвидность** относятся к одной группе. Для бейджа дополнительно нужны свежесть или покупатели.

Если указанная цена отсутствует, некорректна, меньше или равна нулю либо отмечена как подозрительная, бейдж скрываем. Подтверждённые признаки остаются доступны для расшифровки.

## Что нужно отрисовать

| Где | Что показываем |
|---|---|
| **Веб — выдача** | Компактный значок без расшифровки. Он заменяет отдельные значки покупательского спроса и ликвидности. |
| **Веб — дровер** | Индикатор с текстовой расшифровкой подтверждённых признаков. |
| **Веб — страница объекта** | Индикатор с такой же расшифровкой, как в дровере. |
| **Плагин** | Компактный значок без расшифровки. |
| **Мобилка — выдача** | Компактный значок без расшифровки. |
| **Мобилка — страница объекта** | Индикатор с такой же расшифровкой, как в вебе. |

На всех экранах бейдж показываем по одному правилу. В дровере и на страницах объекта выводим все подтверждённые признаки в порядке из таблицы, даже если их недостаточно для бейджа. Для объявлений, к которым фича не применяется, бейдж и расшифровку скрываем.

Индикатор пересчитывается при каждом запросе. Когда истекают 12 часов, тег «Новое объявление» исчезает при следующем обновлении. Если покупателей тоже нет, бейдж скрывается. **Фильтр и сортировку по индикатору не добавляем.**
