# Поиск уникальных объектов

## Краткое описание

Фича помогает специалисту по недвижимости находить объекты, с которыми "Этажи" еще не работают. Система собирает объявления из внешних источников, сверяет их с внутренней базой и отдает пользователю очищенный список уникальных объектов для дальнейшей обработки.

## Потребность пользователя

СПН нужно быстро находить новые объекты без ручного просмотра всех площадок и без траты времени на уже известные дубли.

## Поведение

Система регулярно получает объявления из агрегаторов и сайтов агентств недвижимости в выбранном городе. Для всех подключенных городов проверяются федеральные источники: Яндекс Недвижимость, Циан, Домклик и Авито. Дополнительно город сообщает, какие локальные площадки и агентства недвижимости важны для региона, и эти источники добавляются в список проверок. После этого каждый найденный объект сравнивается с базой "Этажей".

Объект считается дублем, если совпадает по адресу, основным характеристикам и ценовым параметрам. В проверку входят адрес, комнатность, площадь, этаж, этажность дома, цена и цена за квадратный метр. Для цены и площади допускается расхождение до 10%.

Если объект уже есть в базе или распознается как дубль существующего объекта, он исключается из выдачи. Если парсеру недостаточно данных для уверенного определения дубля, система должна позволять вручную связать найденный объект с объектом из базы "Этажей". После ручного связывания объект считается дублем и убирается из выдачи уникальных объектов.

Авторизоваться в RHOOD может любой сотрудник компании "Этажи". Выдача показывается только для подключенных городов. Если город пользователя не подключен, система сообщает, что в этом городе парсер ничего не ищет.

Пользователь видит только свой городской контур. Если вместе с основным городом подключены города-спутники, пользователь видит все города этого контура и может выбирать их в фильтрах.

## Состояния

- Пустое состояние: уникальные объекты не найдены или фильтры слишком ограничили выборку.
- Загрузка: идет сбор данных, сравнение источников или применение фильтров.
- Успешное состояние: пользователь видит список уникальных объектов, готовых к обработке.
- Ошибка: часть источников недоступна, сравнение не завершено или данные не удалось загрузить.
- Недоступно или отключено: город не подключен, для него еще не настроены источники или парсинг временно отключен.

## Крайние случаи

- Один и тот же объект опубликован на нескольких площадках с разными адресами, ценами или неполными данными.
- В объявлении недостаточно данных для автоматического сопоставления, и решение о дубле принимает пользователь вручную.

## Связанный интерфейс

- Экраны: `Набор базы`, список объектов, режим группировки дублей.
- Компоненты: таблица объектов, фильтры, сортировка, статусы, действия по объекту, модальное окно ручного связывания дубля.
- Спецификация интерфейсов выдачи: [Режимы выдачи объектов](./search-results-views.md).

## Связанные данные

- Сущности: объект недвижимости, источник, дубль, уникальный объект, статус обработки, связь с объектом из базы "Этажей".
- Входные данные: объявления из внешних источников, база объектов "Этажей", параметры города и фильтров, правила доступности городов и городов-спутников.
- Выходные данные: список уникальных объектов, готовый для просмотра и взятия в работу.
