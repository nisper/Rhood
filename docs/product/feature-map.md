# Карта функционала

Этот документ хранит основные продуктовые области и ссылки на подробные описания фич.

## Фичи

### Набор базы

1. [[Поиск уникальных объектов]]
   Сбор объектов из внешних источников и выделение уникальных объектов, с которыми "Этажи" еще не работают.
2. [[Группировка объявлений по объекту]]
   Поиск связанных объявлений одного объекта и раскрытие этой группы из строки объявления в выдаче.
3. [[Мэтчинг покупателей]]
   Автоматическая проверка объектов из парсера на наличие подходящих покупателей в базе "Этажей".
4. [[Сохраненные фильтры]]
   Повторное применение сохраненных параметров фильтра; связанная фича — [[Подписка на поиск]].
5. [[Подписка на поиск]]
   Сохранение поиска и подписка на него; баннер после изменения фильтра — один из способов привлечения к подписке.
6. [[Подписка Rhood Plus]]
7. [[Рейтинг специалистов]]
   Фича стимулирует пользователей набирать базу постоянным участием в рейтинге.
