# Карта функционала

Этот документ хранит основные продуктовые области и ссылки на подробные описания фич.

## Фичи

| Область    | Фича                                                                          | Описание                                                                                                 | Статус   |
| ---------- | ----------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------- | -------- |
| Набор базы | [Поиск уникальных объектов](./features/unique-listings-discovery.md)          | Сбор объектов из внешних источников и выделение уникальных объектов, с которыми "Этажи" еще не работают. | Черновик |
| Набор базы | [Группировка объявлений по объекту](./features/listing-grouping-by-object.md) | Поиск связанных объявлений одного объекта и раскрытие этой группы из строки объявления в выдаче.         | Черновик |

## Статусы

- `Идея` - стоит зафиксировать, но еще не сформулирована подробно.
- `Черновик` - фича описывается или исследуется.
- `Готово к работе` - достаточно понятно для дизайна или реализации.
- `В работе` - активно проектируется или разрабатывается.
- `Запущено` - доступно в продукте.
- `На паузе` - осознанно отложено.

## Заметки

- По возможности сохраняй названия областей и фич стабильными.
- Лучше ссылаться на отдельные файлы фич, чем добавлять сюда длинные описания поведения.
