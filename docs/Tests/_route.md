# Маршрут к проверкам

Используй эту инструкцию, когда пользователь просит выполнить проверки из `docs/Tests/_route.md`.

## Порядок работы

1. Определи, какие компоненты или фичи ты создал, изменил или собрал в рамках задачи.
2. Найди ниже инструкции, относящиеся к этим компонентам или фичам.
3. Выполни все подходящие проверки из найденных инструкций.
4. Если проверку невозможно выполнить, укажи, что именно помешало. Не отмечай такую проверку как выполненную.
5. В конце перечисли выполненные проверки и их результат.
