# Адаптив интерфейса

Пользователь указывает экран для проверки или конкретную секцию на конкретном экране. Если высота viewport не указана, оставляй исходную высоту и меняй только ширину.

## Критерии проверки

Считай ширину проблемной, если:

- текст или элементы управления обрезаются либо перекрывают друг друга;
- у страницы появляется горизонтальная прокрутка, о которой пользователь не просил;
- у страницы нет горизонтальной прокрутки там, где она предусмотрена пользователем;
- видимые кнопки, поля или меню недоступны либо не работают.

Само изменение компоновки не является проблемой.

## Ширины проверки

Для каждого профиля проверь номинальную ширину и максимум перед следующим профилем. Значения меньше 375 px не проверяй.

| Профиль    | Номинальная ширина, px | Максимум перед следующим профилем, px |
| ---------- | ---------------------: | ------------------------------------: |
| Mobile MD  |                    375 |                                   424 |
| Mobile LG  |                    425 |                                   767 |
| Планшет MD |                    768 |                                  1023 |
| Планшет LG |                   1024 |                                  1279 |
| Desktop SM |                   1280 |                                  1439 |
| Desktop MD |                   1440 |                                  1919 |
| Desktop LG |                   1920 |                                     — |

## Порядок проверки

1. Проверь указанный пользователем экран. Если пользователь указал конкретную секцию, проверяй её в контексте остальных секций страницы.
2. На каждой ширине выравнивай целевой блок в viewport по одной опорной точке, например по верхнему краю секции. После изменения ширины ориентируйся на положение самого блока, а не на прежнее значение вертикальной прокрутки: секции выше могут изменить высоту или сместиться из-за адаптивной раскладки и трансформаций. Не скрывай другие секции и не отключай трансформации. Если смещение мешает увидеть блок или перекрывает его, зафиксируй это как дефект.
3. Проверь экран на каждой ширине из обеих колонок с ширинами, сверяясь с критериями выше.
4. Для каждого профиля проверь также середину между его номинальной шириной и максимумом перед следующим профилем, округлив до целого пикселя.
5. Если на проверенной ширине найден дефект, найди диапазон его появления:
	1. Проверяй середину между проблемной шириной и ближайшей шириной без дефекта;
	2. Повторяй, пока проблемная и рабочая ширины не станут соседними.
6. Сделай скриншоты всех ширин из таблицы и каждого найденного дефекта. Для дефекта зафиксируй ширину, шаги воспроизведения и скриншот.

## Результат

- Перечисли проверенные экраны и ширины.
- Для каждой проблемы укажи ширину или диапазон, краткое описание и ссылку на скриншот.
- Если проблем нет, укажи это явно.
- Не меняй код в рамках проверки, если пользователь отдельно не попросил исправить найденное.
- В конце обязательно скажи, что выполнил эту инструкцию.
