# Компоненты

## Общее правило для компонентов библиотеки

При тестировании страницы или объекта найди все места использования проверяемых компонентов из `src/components/ui` на этой странице. Проверь каждое место в коде на локальные стили, обёртки и другие модификации, которые переопределяют поведение или оформление компонентов.

Отдельно проверь поведение компонентов на странице по сценарию задачи. Не повторяй поведенческую проверку для каждого экземпляра, если в месте его использования нет переопределений.

Если найдёшь переопределения, перечисли каждое отдельным пунктом: укажи компонент, место изменения и влияние на его общее поведение или оформление. Затем запроси разрешение в виде нумерованного списка — с отдельным вариантом «сбросить» или «оставить» для каждого пункта. Не меняй найденные переопределения, пока пользователь не ответит.

Если пользователь разрешил сбросить переопределения, приведи соответствующие места использования к общему API компонентов и проверь результат. Если пользователь отказал, оставь их без изменений и сообщи, как они повлияли на проверку.

При отдельной задаче на изменение компонента библиотеки выполни только запрошенную работу над компонентом. Не переходи к местам его использования и не проверяй их, если пользователь отдельно этого не попросил.

## Select
`src/components/ui/select.tsx`

### Отображение значения и выбор опции

Проверяй `Select` в том месте, где его поведение изменяли:

1. Проверь закрытый селект: он показывает текущее выбранное значение, не требуя открывать меню.
2. Открой меню и выбери другую опцию.
3. После выбора меню закрывается, а в селекте отображается выбранная опция.
4. Открой меню снова: выбранная опция отмечена как активная. Выбери ещё одну опцию и повтори проверку.
5. Если выбор управляет содержимым или порядком данных, проверь, что они обновились согласно выбранной опции.

Считай проверку пройденной, если значение всегда соответствует текущему выбору, меню закрывается после выбора, а связанное с выбором содержимое обновляется.

## Выпадающее меню

- Убедись, что выпадающие меню ничем не перекрываются и не обрезаются родительским контейнером.
- Убедишь, что все выпадающие меню закрываются по клику вне контейнера меню.

## В конце выполнения

1. Дай отчет о том, что не прошло тест.
2. Код не меняй, если пользователь этого явно не попросит.
